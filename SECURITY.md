# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v0.1.0   | :white_check_mark: |


## Reporting a Vulnerability

Please contact [security@lentil.org](mailto:security@lentil.org) to report security issues or discuss security concerns. You can also [submit security issues securely via GitHub here](https://github.com/listerr/roundcube-ai-backend/security/advisories/new).

DO NOT report via a github issue, PR or public forum.

If you need to share sensitive information, please request my pgp key, or email and request another channel such as Signal.

Thank you in advance for responsibly reporting security issues.

## Process

After a security vulnerability is reported and verified, I will attempt to resolve it in as timely a fashion as possible.

Security fixes will be made available on github.

As the tests for security vulnerabilities are often nearly identical to working exploits, sensitive tests will be embargoed for a period of six months before being added to the public repository.

Unless otherwise notified, reporters will be acknowledged in the release notes.
